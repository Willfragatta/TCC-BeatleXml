# Diagramas UML

Esta pasta reúne os diagramas de modelagem do sistema, elaborados na etapa de Prototipação e Modelagem (PlantUML).

Arquivos previstos:

- casos_de_uso.puml — atores: contador, gestor e agente desktop
- entidade_relacionamento.puml — modelo físico PostgreSQL
- classes_backend.puml — serviços de integração SEFAZ e processamento XML
- implantacao.puml — Nginx, FastAPI, workers e Beatle Uploader
- sequencia_sefaz.puml — fluxo assíncrono de consulta à SEFAZ

Os diagramas completos estão no documento do TCC (Figuras 2 a 6). Os arquivos `.puml` serão adicionados conforme a modelagem for exportada do PlantUML.
